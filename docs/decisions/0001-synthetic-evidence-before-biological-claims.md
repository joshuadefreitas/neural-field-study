# 0001: Synthetic Evidence Before Biological Claims

## Context

The study uses concepts from neural-field theory and produces persuasive spatial patterns, but it has synthetic inputs, manually selected parameters, a finite periodic lattice, and no fit to neural recordings. Without an explicit decision, visual output could be mistaken for biological evidence.

## Decision

Treat the repository as an abstract discrete rate-field study. Every public finding must identify the exact configuration and be supported by reproducible code and numerical evidence. Literature citations establish conceptual context only. Biological or clinical claims require a separate public dataset, provenance record, validation protocol, and decision record.

## Consequences

- The browser study remains an evidence surface for a declared synthetic system.
- Numerical labels such as persistent spatial structure are not biological regimes.
- New topology, data, or GPU work requires a documented update to the evidence boundary.

## Alternatives Considered

- Describe the current field as a brain simulation: rejected because no biological data or validation supports it.
- Avoid neural-field terminology entirely: rejected because the literature provides useful conceptual context when the implementation boundary is explicit.
